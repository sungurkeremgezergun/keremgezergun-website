Sık sorulan sorular

HAR dosyası nedir?

HAR (HTTP Archive), bir web sayfasının ağ isteklerinin kaydıdır. Chrome/Edge/Safari geliştirici araçlarında Network sekmesini açıp sayfayı yenileyin, sonra sağ tık → Save all as HAR. Bu dosyayı Knotvo'da açıp analiz edin.

Verilerim Mac'imden çıkıyor mu?

HAR analizi %100 yereldir — hiçbir şey yüklenmez. Opsiyonel canlı URL ölçümü özelliği yalnızca girdiğiniz URL'i Google PageSpeed Insights'a gönderir. Gizlilik Politikası'na bakın.

Canlı ölçüm "kota doldu" diyor veya anahtar istiyor.

Canlı ölçüm, Google'ın ücretsiz PageSpeed Insights API'sini kullanır. Google Cloud Console'dan ücretsiz bir API anahtarı oluşturun (kredi kartı gerekmez, günde 25.000 sorgu) ve Ayarlar → PageSpeed Insights API Anahtarı'na ekleyin.

localhost / staging / şifreli bir sayfayı test edebilir miyim?

Canlı ölçüm yalnızca herkese açık URL'lerde çalışır (Google sayfaya erişebilmeli). Özel veya iç sayfalar için tarayıcınızda HAR kaydı alıp Knotvo'da açın.

Sır içeren bir HAR'ı güvenle nasıl paylaşırım?

Sanitize → Paylaşıma Güvenli Kopya kullanın. Knotvo çerezleri, Authorization başlıklarını, token'ları ve gövde sırlarını kaldırıp yerel olarak temiz bir kopya üretir; orijinal dosyanız hiç değişmez.

Her şeyi nasıl sıfırlarım?

Ayarlar → Tüm veriyi sıfırla tüm markaları, siteleri, taramaları, API anahtarınızı ve tercihlerinizi kalıcı olarak siler.

Frequently asked questions

What is a HAR file?

A HAR (HTTP Archive) file is a log of a web page's network requests. In Chrome/Edge/Safari DevTools, open the Network tab, reload the page, then right-click → Save all as HAR. Open that file in Knotvo to analyze it.

Does my data leave my Mac?

HAR analysis is 100% local — nothing is uploaded. The optional live URL measurement feature sends only the URL you enter to Google PageSpeed Insights. See our Privacy Policy.

Live measurement says "quota exceeded" or asks for a key.

Live measurement uses Google's free PageSpeed Insights API. Create a free API key (no credit card, 25,000 queries/day) in the Google Cloud Console, then add it in Settings → PageSpeed Insights API Key.

Can I test a localhost / staging / password-protected page?

Live measurement only works on public URLs (Google must be able to reach the page). For private or internal pages, capture a HAR in your browser and open it in Knotvo instead.

How do I safely share a HAR that contains secrets?

Use Sanitize → Share-Safe Copy. Knotvo removes cookies, Authorization headers, tokens, and body secrets, and produces a clean copy locally — your original file is never changed.

How do I reset everything?

Settings → Reset all data permanently deletes all brands, sites, scans, your API key, and preferences.
